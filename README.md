# **Creación de entornos con Terrain**

**Enunciado de la tarea:**
	En esta actividad he creado un escenario 3D completo en **Unity** utilizando el sistema *Terrain*. He aplicado *texturas* externas, lo he ambientado como un entorno fantástico y, finalmente, he *programado* un controlador en tercera persona que permite recorrerlo.

El objetivo es combinar diferentes aspectos del diseño de entornos, el uso de *materiales* y la *programación* básica de un *controlador* de personaje.
